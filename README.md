# Thuc_nghiệm_countdown

NCKH: so sánh **prompting / SFT / RLVR(GRPO)** trên bài toán Countdown, phần thưởng đến từ
verifier kiểm chứng được.

```
countdown-lab/     toan bo project chay duoc: src/, tests/, data*, configs/, logs/
CONTRIBUTING.md    luat lam viec chung de 2 nguoi khong conflict
```

- Bat dau tu `countdown-lab/README.md` (cau lenh, ket qua da do, han che).
- Tai lieu ly thuyet cua thay: `git clone https://github.com/hieutachi/rl-reasoning-student-guide`
  (repo nay khong chua code chay duoc).
- Ma nguon `countdown-lab/src/` giai nen tu `countdown-lab/countdown-code-bundle.json`
  bang `unpack.py`, theo huong dan muc 3.1 cua trang lab.
